## Research (read 2026-11-10)

- API_runtime_ToolChoice https://docs.aws.amazon.com/bedrock/latest/APIReference/API_runtime_ToolChoice.html : any = "must request at least one tool (no text is generated)"; auto = default; tool = "must request the specified tool. Only supported by Anthropic Claude 3 and Amazon Nova models." No per-model table for any/auto.
- Model cards (https://docs.aws.amazon.com/bedrock/latest/userguide/model-card-meta-llama-4-scout-17b-instruct.md, ...-llama-3-3-70b-instruct.md, ...-llama-3-1-70b-instruct.md, model-card-writer-palmyra-x5.md) each carry the Note: "Tool use and response streaming are supported separately, but not together. A ConverseStream request that includes a toolConfig field fails with `This model doesn't support tool use in streaming mode.` Use the non-streaming Converse operation when you need tool use." Llama 3.3 card lists no "Client-side tool calling" feature at all; Llama 4 Scout card also lists none.
- Mistral Large (2402) and Pixtral Large cards: no streaming note; Mistral Large 2402 lists Client-side tool calling, Pixtral Large lists it too.
- Qwen3 32B card: client-side tool calling listed only under bedrock-mantle; bedrock-runtime list has no tool calling entry; no streaming note.
- Models-at-a-glance page lists no Llama 3.2/Maverick restrictions; model-card page lists Palmyra X4/X5, Pixtral Large, Mistral Large, Mistral Large 3.
- Not read: AWS tool-use page (tool-use-inference-call.html returned a shell page via fetch), re:Post threads (see below if added).
- AWS "Client-side tool use" https://docs.aws.amazon.com/bedrock/latest/userguide/tool-use-client-side.html (read 2026-11-10): toolChoice settings "depend on the individual model ... not on the model provider or family"; `auto` supported by every tool-capable model; `any` and `tool` supported by some, a model can support one and not the other; unsupported -> ValidationException "This model doesn't support the toolConfig.toolChoice.tool field. Remove ... and try again." (some models return the provider's error instead). ConverseStream rejects tools ("This model doesn't support tool use in streaming mode.") for: Llama 3.1 8B/70B, Llama 3.3 70B, Llama 4 Scout/Maverick, Mistral Large 1 (24.02), Mistral Large 2 (24.07), Pixtral Large (25.02), Writer Palmyra X4 and X5. "Most models that support tool use also accept toolConfig on ConverseStream."
