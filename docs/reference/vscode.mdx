title: "VS Code settings and commands"
---

What the extension adds to VS Code, taken from `extensions/vscode/package.json` (version 2.14.0 at the time of writing): 19 settings, 39 commands and 21 keybindings. Settings are under **Settings, Extensions, Continuous**, or `continuous.*` in VS Code's own `settings.json`. Keys are written for Windows and Linux; on macOS `ctrl` is `cmd` unless the table says otherwise.

## Settings

| Setting                                   | Type    | Default     | What it does                                                                                                                         |
| ----------------------------------------- | ------- | ----------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| `continuous.enableTabAutocomplete`        | boolean | `true`      | Tab autocomplete                                                                                                                     |
| `continuous.enableNextEdit`               | boolean | `true`      | [Next edit](/ide-extensions/autocomplete/next-edit)                                                                                  |
| `continuous.pauseTabAutocompleteOnBattery` | boolean | `false`    | Pause autocomplete when the battery is low                                                                                           |
| `continuous.pauseCodebaseIndexOnStart`    | boolean | `false`     | Do not start indexing the codebase when the window opens                                                                             |
| `continuous.showInlineTip`                | boolean | `true`      | Show the inline hint about the keyboard shortcuts                                                                                    |
| `continuous.disableQuickFix`              | boolean | `false`     | Turn off the quick fix                                                                                                               |
| `continuous.enableQuickActions`           | boolean | `false`     | The experimental Quick Actions code lens                                                                                             |
| `continuous.enableConsole`                | boolean | `false`     | A console in the bottom panel that logs model inputs and outputs. See [Troubleshooting](/troubleshooting#check-the-logs)            |
| `continuous.shareModelsWithVSCode`        | boolean | `true`      | Offer the chat models of the selected config to VS Code's own chat and agents. See [VS Code chat and agents](/customize/vscode-chat-and-agents) |
| `continuous.shareMcpServersWithVSCode`    | boolean | `true`      | Offer the config's MCP servers to VS Code's own chat and agents                                                                      |
| `continuous.accountsFromVSCode`           | boolean | `false`     | Experimental. Use the accounts added for Continuous in VS Code's Language Models editor as provider accounts                         |
| `continuous.terminal.shell`               | `default`, `wsl`, `container` | `default` | Where the agent's terminal commands run. Machine setting. See [Terminal in WSL](/ide-extensions/agent/terminal-in-wsl) and [in a container](/ide-extensions/agent/terminal-in-container) |
| `continuous.terminal.wslDistro`           | string  | empty       | The WSL distribution; empty uses the default one. Machine setting                                                                    |
| `continuous.terminal.containerRuntime`    | `auto`, `docker`, `podman` | `auto` | `auto` uses Docker when installed, else Podman. Machine setting                                                                |
| `continuous.terminal.containerImage`      | string  | empty       | The image; empty uses `ubuntu:24.04`. Machine setting                                                                                |
| `continuous.telemetryEnabled`             | boolean | `true`      | **Deprecated, has no effect.** Continuous collects no telemetry; the setting is kept so existing settings files stay valid           |
| `continuous.remoteConfigServerUrl`        | string  | none        | Upstream's shared-configuration server. Application scope                                                                            |
| `continuous.userToken`                    | string  | none        | The token for that server. Application scope                                                                                         |
| `continuous.remoteConfigSyncPeriod`       | number  | `60`        | Minutes between syncs with that server                                                                                               |

A machine setting cannot be changed by a workspace's settings, so a repository cannot choose where commands run. The last three settings come from upstream's remote configuration feature; this fork documents no server for them.

## Keybindings

| Command                                         | Windows, Linux       | macOS               | When                                                     |
| ----------------------------------------------- | -------------------- | ------------------- | -------------------------------------------------------- |
| Add Highlighted Code to Context and Clear Chat  | `ctrl+l`             | `cmd+l`             | always                                                   |
| Add to Chat                                     | `ctrl+shift+l`       | `cmd+shift+l`       | always                                                   |
| Add to Edit                                     | `ctrl+i`             | `cmd+i`             | always                                                   |
| Exit Edit Mode                                  | `escape`             | `escape`            | in Edit mode, editor focused                             |
| Accept Diff                                     | `shift+ctrl+enter`   | `shift+cmd+enter`   | a diff is shown                                          |
| Reject Diff                                     | `shift+ctrl+backspace` | `shift+cmd+backspace` | a diff is shown                                      |
| Reject Diff                                     | `ctrl+z`             | `cmd+z`             | a diff is shown                                          |
| Accept Vertical Diff Block                      | `alt+ctrl+y`         | `alt+cmd+y`         | always                                                   |
| Reject Vertical Diff Block                      | `alt+ctrl+n`         | `alt+cmd+n`         | always                                                   |
| Apply code from chat                            | `alt+a`              | `alt+a`             | always                                                   |
| Debug Terminal                                  | `ctrl+shift+r`       | `cmd+shift+r`       | always                                                   |
| Open in new window                              | `ctrl+k ctrl+m`      | `cmd+k cmd+m`       | terminal not focused                                     |
| Toggle Autocomplete Enabled                     | `ctrl+k ctrl+a`      | `cmd+k cmd+a`       | terminal not focused                                     |
| Force Autocomplete                              | `ctrl+alt+space`     | `cmd+alt+space`     | editor focused, no selection, not read-only              |
| Toggle Next Edit                                | `ctrl+k ctrl+n`      | `cmd+k cmd+n`       | editor focused                                           |
| Accept Next Edit Suggestion                     | `tab`                | `tab`               | a next edit is shown                                     |
| Hide Next Edit Suggestion                       | `escape`             | `escape`            | a next edit is shown                                     |
| Accept Jump Suggestion                          | `tab`                | `tab`               | a jump suggestion is shown                               |
| Reject Jump Suggestion                          | `escape`             | `escape`            | a jump suggestion is shown                               |

Two more keybindings are defined and disabled: `up` and `down` for `continuous.quickEditHistoryUp` and `continuous.quickEditHistoryDown`. Their condition starts with `false`, and no command of that name exists, so they never fire.

To change a key, use **Preferences: Open Keyboard Shortcuts** and search for `continuous`.

Four titles carry the category twice in this version, so the palette shows them as **Continuous: Continuous: Force Autocomplete**, **...: Force Next Edit**, **...: Accept Jump Suggestion** and **...: Reject Jump Suggestion**.

**Enter Enterprise License Key** is an upstream command. Continuous has no licence; the command has nothing to unlock.
