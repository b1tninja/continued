## How to Use Text Input

Typing a question or instructions into the input box is the only required context.

## How to Include Highlighted Code

The highlighted code you've selected by pressing cmd/ctrl + L (VS Code) will be included in your prompt.

## How to Include the Active File

You can include the currently open file as context by pressing opt/alt + enter when you send your request.

## Add files from the Explorer or tabs

In VS Code, right-click to add files and folders to the chat input:

- **Explorer**: select one or more files or folders, right-click, and choose **Add to Continuous Chat**.
- **Editor tab**: right-click the tab and choose **Add to Continuous Chat**, or **Add All Open Tabs to Continuous Chat** for every open tab.
- **Editor**: with nothing selected, right-click in the file and choose **Continuous** > **Add to Continuous Chat**. With code selected, **Add to Chat** adds the selection instead.
- **Command Palette**: **Continuous: Add to Continuous Chat** adds the active file; **Continuous: Add All Open Tabs to Continuous Chat** adds every open tab.

A file becomes an `@` file chip, the same as picking it from '@Files': it is read when you send, not when you add it. A folder becomes an `@` folder chip, which is a search scope rather than the folder's whole contents, and needs the `folder` context provider in your configuration. The chat opens if it is closed, the input is focused, and a chip already in the message is not added again.

Some files are not added, and a notification says which and why:

- Files that look like they hold secrets: `.env` files, keys and certificates (`*.pem`, `*.key`, `id_rsa`), and folders such as `.ssh` and `.aws`. This is the same list the '@Files' picker leaves out.
- Files outside the workspace folders, such as a tab opened from another folder.
- Unsaved editors.

This works with remote (SSH, WSL, containers) and virtual workspaces. There is no default keyboard shortcut; to add one, bind `continuous.addToChat` or `continuous.addOpenTabsToChat` in **Keyboard Shortcuts**.

## How to Include a Specific File

You can include a specific file in your current workspace by typing '@Files' and selecting the file.
